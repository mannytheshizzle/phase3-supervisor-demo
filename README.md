# Household supervisor demo — static release

Non-commercial demonstration only. No scientific model, recruitment or response upload. Records stay in each browser. All required assets/notices are under site/. This repository payload contains no research source history, transcripts or session records.

Publication requires owner approval. Set Settings → Pages → Source: GitHub Actions. Protect the github-pages environment with an owner reviewer if your plan supports it; select the approved deployment branch. In Actions manually run Publish approved demo release and enter PUBLISH_DEMO. The confirmation is an operator safeguard, not proof of consent or a replacement for GitHub permissions. No automatic push deployment exists. Use only the URL returned by the successful deployment job, then verify the full clean-browser workflow.

For local preview: python3 -m http.server 8080 --directory site
